# 🚀 Cyber-Glow Frontend Developer Portfolio

Welcome to my personal portfolio repository! This is a futuristic, highly responsive, and pixel-perfect portfolio web application designed with a dark glassmorphic cyber-glow aesthetic. Built from scratch using **React.js** and styled with an advanced, clean **Sass (SCSS) architecture**.

---

## ✨ Key Features

- **🌐 Futuristic UI/UX:** High-contrast dark neon theme featuring responsive dynamic background glow accents, traveling data dots, and floating particles.
- **⚡ Seamless Infinite Marquee:** A mathematically looping technology marquee banner built inside an independent standalone component, optimized for fluid horizontal scrolling.
- **🎨 Responsive Glass Layouts:** Pure flexbox and grid layouts carefully engineered with custom media queries to eliminate dead space across all desktop, tablet, and mobile displays.
- **🧠 Advanced Component Architecture:** Clean, state-driven dynamic project maps showcasing live links and repository endpoints.
- **💼 Interactive Cyber Timeline:** A custom structured vertical history timeline highlighting educational certifications and freelance training workflows.
- **📥 Fully Integrated Contact Hub:** Includes instant client mail messaging handling via async fetch APIs alongside direct WhatsApp click-to-chat hooks.

---

## 💻 Core Technical Stack

- **Frontend Core:** React.js (Functional Components & Custom State Management)
- **Styling Architecture:** Sass / SCSS (Advanced Nesting, Variables, Mixins, Dynamic Media Queries)
- **Interactive Assets:** React Icons (`fa` & `ri` bundles)
- **Deployment Platform:** Netlify Production Servers

## 📦 Getting Started & Local Installation

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd your-portfolio-repo-name
   ```

3. **Install the required dependencies:**
   ```bash
   npm install
   ```

4. **Launch the local development server:**
   ```bash
   npm run dev
   ```

5. **Compile and build for final production:**
   ```bash
   npm run build
   ```
